# Basketball Modes hub contract

Version: 1.0.1 · Route: `/clash/modes`.

The Light Court hub lists current and new Basketball surfaces with one-line descriptions, explicit labels, and links. Any Five, Daily, Franchise, Tonight, Spin, filters, Gauntlet, Lab and Private Rooms link to `/clash/…` routes. The existing Chaos, Dream, Best of 7, Win 82, Tournament and Challenges surfaces remain reachable. Fantasy links to format information rather than pretending an unavailable game is playable.

The global All Modes navigation plus each card is a two-tap entry from the home surface on mobile. Filters have their own concise three-choice page; each filter also has a stable direct route. Salary Cap is a visible data blocker, with no fabricated salary pool or misleading Play CTA.

Every new mode uses the ivory/cream content surface, gold primary actions, cobalt Team Blue, existing font and brand tokens, and at least 44-pixel controls. Comboboxes support keyboard selection, explicit labels, live error feedback and decade disambiguation. Mobile content must not overflow horizontally. The server configuration can be retried without losing a completed result; unavailable stores/providers are stated rather than replaced with invented gameplay.

The hub does not change existing account gates by itself. The parent route/gate integration owns guest parity of legacy modes and must report any unresolved dependency. Actual route crawl, mobile viewport, touch-size and accessibility evidence is required in the three-run ledger. A link inventory is not proof of a playable deployed journey.
