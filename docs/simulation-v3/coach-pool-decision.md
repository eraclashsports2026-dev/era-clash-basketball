# Coach pool decision

**25 → 30.** No coach was removed.

## Selection principle

Added for **tactical diversity the pool could not express**, never for fame. The
test: does this coach let a lineup be evaluated against a system no existing
coach represents?

The five additions bracket **three axes at both poles**, which is worth more
than five good coaches clustered in the middle:

| Axis | Low pole | High pole |
| --- | --- | --- |
| **Tempo** | **Mike Fratello** (tempo 1) — slowest team pace in NBA history, 82.32 | **Doug Moe** (tempo 10) — highest scoring average in NBA history, 126.48 PPG |
| **Rotation depth** | **Tom Thibodeau** (2) — heavy starter minutes | **Hubie Brown** (10) — ten-man rotation |
| **Interior geometry** | *(existing post-centric coaches)* | **Stan Van Gundy** (insideOut 10) — four shooters around one centre |

## Additions

| Coach | Record | Distinctive contribution |
| --- | ---: | --- |
| **Doug Moe** | 628-529 | No set plays, two-second ball-hold rule. The pool had no maximum-pace, maximum-movement, defence-indifferent system |
| **Mike Fratello** | 667-548 | Extreme tempo suppression. Nothing in the pool sat below tempo 3 |
| **Hubie Brown** | 357-476 | Ten-man rotation and defence-first teaching. `rotationDepth` had no exemplar at either extreme |
| **Tom Thibodeau** | 578-420 | Elite modern defensive system with the opposite rotation philosophy |
| **Stan Van Gundy** | 554-425 | Four-out/one-in around a dominant centre — the archetype `insideOut` exists to describe |

**Hubie Brown has a losing NBA record (.429) and was added anyway.** The pool is
not a hall of fame; it is a set of *systems* a roster can be evaluated against.
He won an ABA title and Coach of the Year in two different eras 26 years apart,
and his ten-man rotation is a tactical position nothing else in the pool holds.

## Evaluated, not added

| Coach | Why not |
| --- | --- |
| **Frank Vogel** | 480-422 with a 2020 title — credible, but his drop-coverage defensive profile overlaps Thibodeau's. A third similar system adds less than bracketing an axis |
| **Nate McMillan** | Solid record, no distinctive system the pool lacks |

## Replacements

**None.** No existing coach was removed. Every one of the 25 still represents a
system, an era, or a roster philosophy the pool would lose.
