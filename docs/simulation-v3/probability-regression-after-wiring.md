# Probability regression after wiring

**State: MEASURED. Default output unchanged to four decimals.**

Estimates on prediction seeds, measured on probability-validation seeds. Disjoint
sets, both disjoint from actual-game seeds. 30 cells, `STANDARD` tier, 256
independent validation games each.

## Default parity

| Metric | Pre-wiring (6C2C2) | Post-wiring |
|---|---|---|
| Monte Carlo Brier (outcome scale) | 0.2209 | **0.2209** |
| Irreducible floor | 0.2192 | **0.2192** |
| Fraction of achievable skill | 0.9458 | **0.9458** |
| Monte Carlo log loss | 0.6306 | **0.6306** |
| Expected calibration error | 0.0145 | **0.0145** |
| Maximum calibration error | 0.0312 | **0.0312** |
| Sharpness | 0.1836 | **0.1836** |
| Upset rate / favourite win rate | 0.100 / 0.963 | **0.100 / 0.963** |
| Max per-cell raw side bias | 0.0781 | **0.0781** |

Because the default parameter set reproduces the engine exactly, the probability
estimator — which samples that engine — reproduces its output exactly. That is
the expected consequence, and measuring it is how the expectation becomes a fact.

Rate-scale Brier moved from 0.0018 to 0.0017 with the constant baseline moving
0.0308 from 0.0323, both from the fixture-metadata change rather than from engine
behaviour. **Rate-scale and outcome-scale Brier remain incomparable** and only
outcome-scale numbers are set against the 0.2507 analytical baseline.

## Gate

| Check | Result |
|---|---|
| Beats analytical baseline (outcome scale) | PASS |
| Beats constant-0.5 (outcome scale) | PASS |
| Within irreducible floor + 0.01 | PASS |
| Captures ≥ 75% of achievable skill | PASS (0.946) |
| Calibration error ≤ 0.10 | PASS (0.0145) |
| Side bias not systematic | PASS |
| Sharpness reported | PASS |
| Per-cell raw side bias ≤ 0.05 | **FAIL — threshold, not moved** |

The per-cell failure is carried forward from 6C2C2 unchanged and unmoved. That
diagnostic is measured on 256-game samples where the standard error of a 0.5 rate
is 3.13pp, so 0.0781 is 2.5 SE; the systematic test passes clearly at t = −1.29,
and the actual-game symmetry gate passes at 240,000 games. Raising the threshold
would require a policy version bump with a justification independent of the
result, which is a later decision.

## Candidate parameter identity

A non-default set produces a different `parameterSetHash`, a different
`predictionFingerprint`, and therefore a different probability cache key. A test
asserts a candidate result replays exactly and does not leak into a later default
run.

The Monte Carlo cache key already carried `parameterSetHash`. Before this phase
that hash described a registry the engine never read, so two estimates with
different keys could have been generated by identical behaviour — a cache
distinction with nothing behind it. It now describes runtime behaviour.

## Unchanged limitations

Every validation cell is synthetic and every outcome is engine output. This
measures the estimator against the engine, not the engine against basketball.
The engine remains **uncalibrated**: `possessionCalibrationVersion` is `null` and
all 53 parameters sit at their defaults. Calibration at the extremes is still
unestablished — one cell below 0.1, none above 0.9.
