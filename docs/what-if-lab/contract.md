# What-If Lab contract

Version: 1.0.0 · Route: `/clash/lab` · Tag: `LAB`.

Guests choose five canonical decade cards, an opponent, a researched existing coach, and one of the eight existing basketball era environments. A selected player may receive an imagined team label for the scenario. That label is presentation metadata; it does not create franchise chemistry, a new statistical slice, player capabilities, or an invented team bonus. Era rule changes use only environments already supported by the current engine.

The UI labels every run Exploration and explains which input actually affects the game. `play` produces an authoritative result through the existing game server and shared report/card path. `LAB` is excluded from all leaderboard entries and competitive ratings. No custom rule editor is offered for engine rules that are not already supported.

Player selection, identity validation, and eligible-position assignment are shared with Any Five. Unsupported role combinations are explained and blocked before play because the protected simulation requires canonical eligibility. Scenario metadata must survive saved report serialization where appropriate; arbitrary scenario text stays private in the public recap. Lack of provider support is reported as a release limitation. Existing Candidate 4/calibration/core unchanged. Guest, metadata integrity, supported-rule swap, mobile, Breakdown and crawler-card verification require actual recorded journeys.
