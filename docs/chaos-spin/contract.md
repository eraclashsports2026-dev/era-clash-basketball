# Chaos Spin contract

Version: 1.0.0 · Route: `/clash/spin` · Tag: `SPIN`.

Each PG / SG / SF / PF / C slot receives a random canonical franchise id and card decade, with a nonempty eligible subset of that franchise's documented pool. The thirty franchise identities match Franchise Clash and One Franchise. In particular, Charlotte and New Orleans do not share a raw ambiguous Hornets pool. Historical affiliation proposals can reuse a multi-team decade card; the shown decade belongs to that card rather than a newly computed franchise-only statistical slice. The selection adapter ensures the five constraints can be completed with five different people. The server signs the receipt and stores the official pools. One franchise skip and one era skip are available for the whole draft. A skip changes only the requested axis of the selected slot, preserves global playability, and is enforced by the server. An impossible alternate is refused without consuming the skip.

Classic shows the existing displayed card statistics. Hidden Stats conceals those statistics in both choices and selected rows; it does not alter probabilities, simulation capabilities, or outcomes. Eligible positions, franchise, decade, and canonical person uniqueness remain required. The server checks selections against the official receipt rather than accepting client-supplied constraints.

`spin-start`, `spin-skip`, and governed `play` use the existing `/api/game` authority. The shared result and publication path supplies the card. `SPIN` is a casual mode tag, not competitive human rating. Salary values, player bonuses, and a season stat-sum model are not introduced.

Protected simulation unchanged. Unit evidence covers twenty deterministic spin seeds, valid complete pools, forged-pool rejection, and skips changing one axis while preserving completion. Actual guest, skip-limit, hidden-stat, mobile, card, and provider evidence must be recorded in the three-run ledger.
