# Public result recaps, 2.0.0

Basketball only. Engine and calibration behavior are unchanged.

`POST /api/result` accepts `{resultId, publicRecap:true}` or `{chaosRunId, publicRecap:true}`. The existing HttpOnly guest session must own the completed server record. Foreign sessions, cross-origin requests, missing disclosure consent and browser-supplied scores are rejected. Publication derives one stable 16-character URL from the immutable result and disclosure version, including concurrent requests. Only the winning atomic publication returns `created:true`, so repeated requests do not count extra card-created events. A failed store write returns 503. Public recaps expire 180 days after publication.

The public allowlist contains engine mode and a closed display-mode/tag (plus Daily day or Gauntlet stage when applicable), Gold and Blue lineups with catalog or recorded names and positions, final outcome, score, scope, up to two recorded performers, recorded MVP, era and completion time. Gauntlet cards expose only verified victories, total eras, stages played and completion status. They label N of 7 eras and distinguish latest-stage points from the run win count. Lab cards are marked as imagined scenarios; user-entered scenario/team text is excluded. It contains no account name, session, seed, hidden draft, engine fingerprint, rating, XP, coach IDs, API credentials or source result ID. It is a public recap of a simulated game, not a rated or historically measured result.

The publish/copy button explicitly explains that both lineups and performers become public. Ordinary private result-card exports and governed Challenge invitations retain Cards V1's existing allowlists and attribution rules. Publishing a recap does not create a Challenge, spend an attempt, grant XP or affect competitive ratings. Existing browser-published V1 recaps remain readable, visibly labeled as unverified archives. New V1 publication is rejected.

`/card/:id` and compatible `/result/:id` serve actual result HTML through the existing `/api/share-page` function. No JavaScript, login or immediate redirect is required to read the recap. The CTA enters `/clash/any-five?rematch=<id>` for a guest to draft against the shared Gold five. An expired URL returns a helpful 404 and `Cache-Control: no-store`; negative results are never publicly cached.

The same function serves `?kind=result&id=<id>&format=png&v=2`: deterministic PNG, 1200×630, below 1,000,000 bytes. A bounded process-local cache (32 entries) keys the complete SVG plus renderer version. SVG uses escaped text and the Light Court palette, with no league marks, franchise logos, player likenesses or external image requests. The homepage has an original static PNG at `/og-home.png`. Responses use large-image Open Graph and Twitter metadata including alt text, dimensions and canonical URL.

Score scopes follow stored engine facts: single games show points; Best of Seven and Tournament rounds show games won and series averages; 82-game runs show wins/losses and explicitly label finale performers. No series average is called a single-game result, and no finale score is presented as a season's record.

Franchise preview pages use `kind=franchise&id=<slug>` within the same function. They show curated fives and a clearly unplayed preview, with no invented score or performers. Their CTA enters `/clash/franchise?gold=<id>&blue=<id>&entry=control`. `NEUTRAL_TEAM_NAMING=true` applies neutral naming; configure the same value for the server and browser build. The static-generator owner must generate matching assets after changing that flag.

Human-only progressive enhancement `/share-entry.js` emits closed, anonymous `card_opened` and `rematch_started_from_card` events. It sends no share ID, result ID, lineup, name, seed or token. `src/share.js` and the card composer emit `card_created` after successful server publication and `card_shared` for completed native share-sheet return, successful clipboard copy or a download action. These events describe browser actions, not proven delivery to another person.

Renderer dependencies: [resvg-js](https://github.com/thx/resvg-js). Bundled fonts: [Adobe Source Sans 3 release 3.052R](https://github.com/adobe-fonts/source-sans/tree/3.052R), SIL Open Font License 1.1; license copied beside the font files in `api/_lib/fonts/LICENSE.md`. The renderer loads only these two bundled TTF files, with system-font lookup disabled. Vercel must include the font files in the share-page function bundle.

HTTP and browser evidence is generated separately by `node scripts/loop-sharing-audit.mjs <local-harness-origin>` after building and starting the real handler harness. Local evidence does not establish public hosting, Preview environment configuration, external crawler fetchability or owner release approval.

Reproduce the complete sharing-only guest UI loop with `node scripts/loop-guest-rematch-audit.mjs http://localhost:4320`: a fresh anonymous Chrome context opens a real recap, follows its CTA, types five explicit decade choices, plays through the existing handler, and opens its own verified card. This audit is separate from the full product Run 2/Run 3 and does not claim a physical mobile-device test.
