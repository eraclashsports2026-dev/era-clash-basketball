# EraClash Basketball — Wave 1 tester guide

You're one of five invited testers for a **new simulation engine** running in a
private preview. Same game, new engine under the hood — your job is to tell us
whether results *feel like real basketball*.

## Getting in

1. Open the preview: **https://era-clash-basketball-git-wave1-era-clash.vercel.app**
2. Enter the **access key from your invite** at the "Private preview" screen.
   Your key is yours alone — don't share it or post it anywhere.
3. You stay signed in for a week; if you're asked again, just re-enter the key.

**Confidentiality:** this preview is private. Please don't share screenshots,
links or results outside the test group, and don't put personal or sensitive
information in comments.

## Your session (about 45–60 minutes, split however you like)

**Eight guided scenarios** — open each link, read the one-line instruction at
the top, hit RUN THE SIM, read the postgame, then fill the short
"PREVIEW — rate this result" panel underneath. That panel is the whole point.

| # | Scenario | Link |
|---|---|---|
| 1 | Balanced five vs superstar stack | `/?scenario=w1-s1` |
| 2 | Same rosters, contrasting coaches | `/?scenario=w1-s2` |
| 3 | Same matchup, contrasting Era Styles | `/?scenario=w1-s3` |
| 4 | Movement offense | `/?scenario=w1-s4` |
| 5 | Elite defensive five | `/?scenario=w1-s5` |
| 6 | Size vs small ball | `/?scenario=w1-s6` |
| 7 | Spacing vs interior defense | `/?scenario=w1-s7` |
| 8 | Post mismatch and counters | `/?scenario=w1-s8` |

(Each link is relative to the preview address above.)

**Two free-form games** — build any two teams you like, any coaches, any era.
Rate those results too.

**One rematch** — after any game, run the same matchup again. Did the second
game feel like a different night of basketball, or like a dice roll?

## What useful feedback looks like

- "The 90s defensive team never affected Curry's shooting" beats "felt off".
- If something breaks (blank screen, endless spinner, impossible stat line),
  pick the closest issue category and describe what you did — the result id
  attaches automatically.
- If the preview won't load at all, tell the person who invited you; the
  environment can be restarted quickly.
