# EraClash Basketball — private preview tester guide

Welcome! You're testing a **new simulation engine** ("Candidate 3") in a private
preview. The game looks the same — what changed is how games are simulated.
Your job is to tell us whether results *feel like real basketball*.

## Getting in

1. Open the preview link you were given.
2. Enter your **access key** at the "Private preview" screen (sent to you
   separately — don't share it).
3. Play **Single Game** mode. That's the mode running the new engine; other
   modes intentionally run the current engine.

## After each game

A **"PREVIEW — rate this result"** panel appears under the postgame. Please
fill it — five quick 1–5 ratings, one yes/no, and an optional comment. That
panel is the whole point of this test.

## What to try (6–10 games)

| # | Scenario | The question to answer |
|---|----------|------------------------|
| 1 | A balanced team vs five high-usage superstars | Did roster balance feel meaningful? |
| 2 | The same two rosters, two very different coaches (e.g. Pat Riley vs Steve Kerr) | Did the teams feel strategically different? |
| 3 | The same matchup under two Era Styles (e.g. 1960s vs 2010s) | Did the environment change what mattered? |
| 4 | A movement/shooting team (Curry, Klay, Bird…) | Did off-ball movement and assisted play feel visible? |
| 5 | An elite defensive five (Payton, Jordan, Pippen, Duncan, Robinson) | Did the defense affect shot quality, turnovers, rebounds, fouls believably? |
| 6 | Big lineup vs small ball | Did each construction have real advantages *and* tradeoffs? |
| 7 | Rematch the same game once or twice | Did the rematch feel different without becoming random nonsense? |
| 8 | Read the postgame each time | Did it explain **why** the result happened? |

## Notes

- The preview is invite-only; result links you share only open for people with
  an access key.
- If something looks broken (blank screen, spinner forever, nonsense box
  score), submit feedback with the closest issue category and describe it in
  the comment — the result id is attached automatically.
