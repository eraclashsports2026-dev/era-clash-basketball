# 82-0 colour differentiation

**Evidence:** the owner's 82-0 review (26 screenshots, 2026-09-02). Assets are
not stored in the repository; this document records the observed system and how
each EraClash Basketball candidate differs from it. The measured matrix is
`data/validation/9a1/competitive-color-differentiation.json`.

## What 82-0 reads as

| Dimension | 82-0 |
|---|---|
| Dominant background | dark saturated navy |
| Primary CTA | bright saturated orange, orange outlines |
| Panel system | navy cards, thin borders |
| Accent allocation | orange on tabs, badges, CTAs, outlines, links |
| Navigation | top bar, orange active underline, "Get the App" pill |
| Card language | rounded navy cards with an orange CTA |
| Typography | geometric sans, orange caps labels |
| Result | projected record + letter grade + points |
| Silhouette | **dark navy + orange** |

A theme fails only when it primarily reads as *dark navy + bright orange CTA +
orange outlines*, or as *official NBA red + blue + league marks*. One shared
colour never fails a theme alone; the whole system is evaluated.

Measured hue guards in the matrix: a CTA whose hue sits in 15–36° at saturation
above 0.7 is flagged as orange; a dominant navy is a saturated hue in 205–235°
at low luminance. No candidate's CTA is orange: every theme's primary action is
EraClash gold (hue ≈ 41°) with near-black ink.
